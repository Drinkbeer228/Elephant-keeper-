# Симулятор дежурного кипера слоновника

2D-игра на canvas про дежурство кипера у слоних Одри, Марго и Претти. Чистый JS, без сервера и сохранений.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # dist/
```

- `docs/context.md` — вводная: как устроено настоящее дежурство (перенесена из СлоноВета).
- `docs/divergences.md` — где игра расходится с вводной.
- `old/` — прежние версии (Qwen, keeper-simulator-2.0), в git не входят.
