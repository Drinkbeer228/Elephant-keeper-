# Elephant Keeper

Небольшой слоновник и смена смотрителя. Слоны живут своей жизнью — едят, пьют, играют, купаются, спят, ходят в туалет — и зовут кипера, когда без него не обойтись. У каждой слонихи свой характер, и каждая запоминает, отвечают ли ей.

TypeScript + Phaser 3, векторная графика (Canvas 2D → текстуры), детерминированная симуляция без внешних API.

```bash
npm install
npm run dev         # http://localhost:3000/Elephant-keeper-/
npm run typecheck
npm test
npm run build       # dist/ для GitHub Pages
```

## Как играть

- **WASD / стрелки** — идти, **Shift** — бежать (нервных слонов это пугает)
- **E / Space** — главное действие у станции, слона или вещи; **2…6** — другие варианты; **Q** — положить вещь
- клик по слону или **I** — осмотр (потребности, характер, отношение к киперу); **J** — журнал и распорядок
- **T** — скорость времени (1×/2×/4×), **P / Esc** — пауза и сохранения, **Tab** — обзор территории, **+/−** — масштаб
- на телефоне — экранный стик и кнопки действия

Кипер работает в защищённом контакте: в слоновник или на выгул можно войти, только когда там нет слонов (и ворота между зонами закрыты). Кормить, поить, угощать и звать слонов можно через решётку и ограду.

## Параметры адреса

- `?herd=4` — размер стада (1–6) для новой игры, `?seed=123` — фиксированный seed
- `?autostart=1` — сразу в смену, без заставки
- `?bot=1&speed=4` — смену играет бот-кипер (демо и проверка)

## Устройство

- `src/data/` — план слоновника (`facility.ts`) и все числа баланса (`balance.ts`)
- `src/sim/` — симуляция без Phaser и DOM: генерация стада (`herd.ts`), поведение (`behavior/`), мир (`world.ts`), кипер и его действия (`keeper.ts`), навигация (`nav.ts`), тревоги, итог смены, сохранение (`save.ts`, `storage.ts`)
- `src/render/` — отрисовка состояния (сцена Phaser, слоны, кипер, мир, эффекты)
- `src/ui/` — интерфейс, `src/audio/` — процедурный звук, `src/dev/autokeeper.ts` — бот
- `tests/` — Vitest: генерация, детерминизм, сохранения, физиология, поведение и характер, сигналы и научение, кипер и защищённый контакт, карта, устойчивость, сквозная смена ботом

Подробнее — `docs/architecture.md`.
