# Дежурный кипер

Игра про суточное дежурство кипера при шести слонах — трёх слонихах и трёх самцах: бак, подстилка, тазы и каша, сдача смены по чек-листу.
TypeScript + Phaser 3, логика отдельно от отрисовки. Графика — пиксель-арт в духе NES, собирается кодом.

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # тесты логики смены
npm run build   # dist/
```

**Быстрый запуск из папки:** двойной клик по ярлыку `Start keeper sim` (файл `Start keeper sim.desktop` в корне проекта) или запуск `./start-keeper-sim.sh` предложит выбрать рабочую карту с двумя ограждёнными слоновниками либо новую карту. По умолчанию (`/?map=old`) открывается рабочая версия; новая доступна как `/?map=new`. Если сервер уже запущен, откроется выбранный вариант; иначе сначала поднимется dev-сервер. Иконка ярлыка — `icon.png`, сгенерированная из пиксель-арта слонихи (`node scripts/make-icon.mjs` пересоздаёт её).

Управление: WASD / стрелки — ходить, Space — действие, F — осмотр, Q / E — держать равновесие тюков на тачке, P — пауза, колесо мыши — зум (1.0–2.5), Tab / Z — рабочий план ↔ общий план всей карты. На телефоне — джойстик и кнопки.

- `src/sim/` — логика смены без Phaser и DOM: `createShift(seed)`, `tick(state, dt, commands)`.
- `src/data/` — профили слоних, карта, баланс (`balance.ts`), тексты «почему?».
- `src/art/` — пиксельные спрайты из кода: генератор с контуром и светотенью, палитра, слонихи, кипер, предметы, станции, фон.
- `src/game/` — Phaser: мир, кадры анимации, свет, эффекты, ввод.
- `src/dev/` — бот-кипер (`/?bot&speed=10` — смотреть, как он играет) и лист спрайтов (`/dev-sheet.html?s=6`).
- `src/ui/` — интерфейс поверх игры: часы, события, меню действия, табель с чек-листом сдачи.
- `tests/` — Vitest.
- `docs/context.md` — вводная: как устроено настоящее дежурство.
- `docs/design.md` — дизайн вертикального среза «одна смена».
- `docs/specs/`, `docs/plans/` — спецификации и планы этапов (смена и комплекс, снабжение, стажировка).
- `docs/handoff.md` — передача между чатами: что сделано и что дальше.
- `docs/divergences.md` — расхождения прежней версии (зоопарк) с вводной.
- `legacy/` — прежняя версия из AI Studio, не входит в сборку (тег `legacy-aistudio`).
- `old/` — ещё более старые версии, в git не входят.
