# Дежурный кипер

Игра про суточное дежурство кипера при трёх цирковых слонихах: бак, подстилка, каша, приём и сдача смены.
TypeScript + Phaser 3, логика отдельно от отрисовки. Графика — пиксель-арт в духе NES, собирается кодом.

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # тесты логики смены
npm run build   # dist/
```

Управление: WASD / стрелки — ходить, Space — действие, F — осмотр, Q / E — держать равновесие тюков на тачке, P — пауза. На телефоне — джойстик и кнопки.

- `src/sim/` — логика смены без Phaser и DOM: `createShift(seed)`, `tick(state, dt, commands)`.
- `src/data/` — профили слоних, карта, баланс (`balance.ts`), тексты «почему?».
- `src/art/` — пиксельные спрайты из кода: генератор с контуром и светотенью, палитра, слонихи, кипер, предметы, станции, фон.
- `src/game/` — Phaser: мир, кадры анимации, свет, эффекты, ввод.
- `src/dev/` — бот-кипер (`/?bot&speed=10` — смотреть, как он играет) и лист спрайтов (`/dev-sheet.html?s=6`).
- `src/ui/` — интерфейс поверх игры: часы, события, чек-лист, табель.
- `tests/` — Vitest.
- `docs/context.md` — вводная: как устроено настоящее дежурство.
- `docs/design.md` — дизайн вертикального среза «одна смена».
- `docs/divergences.md` — расхождения прежней версии (зоопарк) с вводной.
- `legacy/` — прежняя версия из AI Studio, не входит в сборку (тег `legacy-aistudio`).
- `old/` — ещё более старые версии, в git не входят.
