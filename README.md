# Дежурный кипер слоновника

Производственный 2D-симулятор суточного дежурства кипера при шести слонах — трёх слонихах в верхнем комплексе (**Претти**, **Марго**, **Одри**) и трёх самцах в нижнем комплексе (**Раджа**, **Барон**, **Цезарь**), где помогает напарник **Димон**.

Движок: **TypeScript + Phaser 3**, детерминированная чистая симуляция (`src/sim/`) отдельно от отрисовки (`src/game/`) и DOM-интерфейса («Журнал дежурного кипера» в `src/ui/`). Вся пиксельная графика (`src/art/`) и звуковая обратная связь (`src/game/sound.ts`, Web Audio API) синтезируются кодом без внешних бинарных ассетов.

```bash
npm install
npm run dev         # http://localhost:3000
npm run typecheck   # проверка типов TypeScript (tsc --noEmit)
npm test            # полный набор модульных и симуляционных тестов Vitest
npm run build       # производственная сборка в dist/
```

## Режимы карты и URL-параметры

- `?map=legacy` (по умолчанию в браузере) — камерная карта 64×48 с двумя слоновниками и двором.
- `?map=new` — расширенный комплекс 120×100 с буферной зоной разгрузки паллет, кормокухней, мойкой, опилочником и двумя открытыми лугами с бассейнами.
- `?autostart=1` — пропуск стартового экрана и мгновенный вход в смену.
- `?bot&speed=10` — демонстрационный прогон смены автономным A*-ботом.
- `?ai=1` — отображение диагностических меток FSM и темперамента над каждым слоном в мире.

Переключатель планировки комплекса (`64×48` ↔ `120×100`) также доступен прямо на стартовом экране и в меню паузы.

## Управление

- **WASD / Стрелки** — движение кипера (на смартфонах и планшетах — экранный стик)
- **Shift** — ускоренный шаг
- **Space / E** — контекстное действие (или срез выбранного дефекта в окне чистки овощей)
- **1–9** — быстрый выбор пункта в меню стоящей тачки / рохли
- **Q / E** — удержание равновесия перегруженной тачки с тюками
- **F** — открыть/закрыть ветеринарное досье слонов и сводку по секторам (также открывается кликом по карточке любого слона в верхней панели)
- **J** — свернуть/развернуть почасовой регламент смены и живой чек-лист приёмки (10 пунктов)
- **Tab / Z** — переключение камеры между рабочим планом и обзором всей территории; колесо мыши — плавный зум (1.0–2.5)
- **M** — включить/выключить процедурный звук
- **P / Esc** — пауза, слоты сохранений (`localStorage`) и экспорт/импорт смены в `.json`

## Архитектура репозитория

- `src/sim/` — детерминированное ядро симуляции без зависимостей от Phaser и DOM:
  - `state.ts`, `tick.ts`, `actions.ts`, `elephants.ts`, `feeding.ts`, `floor.ts`, `barrow.ts`, `truck.ts`, `partner.ts`, `toys.ts`, `handover.ts`;
  - `ai/` — табличный конечный автомат слонов (FSM: `engine.ts`, `states.ts`, `rules.ts`, `types.ts`) с приоритетами состояний, прерываниями и индивидуальными темпераментами (`displayTemperamentOf`, `STATE_LABELS`);
  - `save.ts` и `storage.ts` — каноническая JSON-сериализация смены с поддержкой `Infinity`/`undefined`, проверкой версии схемы и карты, 4 слотами `localStorage` (автосейв + 3 ручных слота) и экспортом/импортом `.json`.
- `src/data/` — профили 6 слонов (`elephants.ts`), баланс (`balance.ts`), карты (`map.ts`, `map-legacy.ts`), зоологические пояснения («почему?», `why.ts`).
- `src/art/` — процедурный генератор пиксель-арта с контуром и светотенью (`pixel.ts`, `palette.ts`, `elephantPx.ts`, `keeperPx.ts`, `itemsPx.ts`, `stationsPx.ts`, `vegPx.ts`, `worldPx.ts`).
- `src/game/` — Phaser-сцены (`world.ts`, `overlay.ts`), представления слонов, кипера и тачки (`elephantView.ts`, `keeperView.ts`, `barrowView.ts`), процедурный звуковой движок (`sound.ts`), ввод (`input.ts`).
- `src/ui/` — интерфейс «Журнал дежурного кипера»: верхняя телеметрия, интерактивные карточки 6 слонов, живое ветеринарное досье, журнал смены с 10-пунктовым чек-листом, менеджер сохранений и итоговый акт сдачи смены (`hud.ts`, `report.ts`, `icons.ts`, `styles.css`).
- `src/dev/` — автономный A*-бот (`bot.ts`) и витрина спрайтов (`/dev-sheet.html`).
- `tests/` — модульные, интеграционные и golden-тесты Vitest.
