# Симулятор дежурного кипера слоновника (2D Retro Canvas Game)

Полноценная автономная 2D ретро-игра в стиле пиксель-арт с видом сверху (top-down), процедурной отрисовкой через HTML5 Canvas API и встроенным синтезатором звуков Web Audio API без внешних зависимостей.

### User Review & Critical Decisions

> [!IMPORTANT]
> Подтвержденные параметры геймплея на основе ответов пользователя:
> - **Продолжительность смены**: Неспешная рабочая смена с 08:00 до 20:00 (~8-10 минут реального времени, со счетчиком и опцией паузы).
> - **Звуковой синтезатор**: Реалистичные процедурные ретро-звуки Web Audio API (шаги по соломе/бетону, шуршание лопаты, всплеск ведра, трубный рев слонов) с кнопкой включения/выключения звука в HUD.
> - **Финал смены (20:00)**: Интерактивный табель дежурства с подробным расчетом KPI кипера, оценкой (S/A/B/C) и памятной медалью зоопарка.

---

### 1. Overview & Core Concept

- **Что это**: Интерактивный симулятор дежурного кипера в закрытом теплом слоновнике зоопарка. Игрок управляет кипером в форменном комбинезоне и сапогах, следит за благополучием трех слоних (**Одри**, **Марго**, **Претти**), наводит чистоту, разносит сено и овощную кашу, вовремя ловит мочу для лабораторных анализов и проводит регулярный осмотр подопечных.
- **Целевая аудитория**: Любители уютных ретро-симуляторов (в духе Stardew Valley / Theme Park), атмосферного пиксель-арта и животных.
- **Главная ценность**: Аутентичная атмосфера зоопарка, медитативный геймплей с четкими и увлекательными микро-задачами, процедурный ретро-арт без единого стороннего файла.

---

### 2. User Experience & Visual Design

- **Пользовательский поток**:
  1. *Title Screen*: Атмосферная заставка с анимированным слоновником, слонихами, приветственным слоганом, перечнем управления (`WASD / Стрелки`, `Пробел / E` — Действие, `F` — Осмотр, `P / Esc` — Пауза, `M` — Звук) и кнопкой «Начать смену».
  2. *Active Shift (08:00 - 20:00)*:
     - Кипер ходит по загонам, коридорам и служебным зонам с честными коллизиями со стенами, ограждениями и туловищами слоних.
     - **Уборка навоза**: слоны периодически оставляют кучи; кипер убирает лопатой в тачку (макс. 60 кг), затем отвозит тачку в контейнер утиля.
     - **Кормление**: кипер берет тюк сена или таз с кашей на складе кормов, несет в индивидуальные кормушки слоних; сытость растет до зеленого уровня.
     - **Ловля анализа**: над слонихой загорается сигнал («Марго готовится к мочеиспусканию!») с таймером; кипер бежит с ведром, запускается мини-игра на реакцию (остановка бегунка в целевой зоне бара), при успехе проба регистрируется в журнал с бонусом.
     - **Осмотр (F)**: при нажатии рядом со слонихой открывается иллюстрированная ветеринарная карточка (уши, бивни/хобот, стопы, хвост, настроение).
  3. *Shift Summary (20:00)*: Торжественный табель кипера со статистикой (убрано кг, роздано корма, взято проб, осмотров), итоговым баллом и медалью («Мастер-кипер», «Старший кипер», «Дежурный практикант») с возможностью начать новую смену.

- **Визуальная стилистика & Палитра**:
  - Палитра теплого закрытого слоновника: бежево-песочный теплый бетон (`#d8c8a8`, `#c2b292`), текстурированная дубовая древесина загонов (`#8b5a2b`, `#5c3a1e`), соломенная подстилка (`#f4d06f`), слоновья серая гамма с объемными тенями (`#6c757d`, `#495057`, мягкие блики).
  - Процедурный пиксель-арт: покачивание слонов, взмахи огромных ушей, шевеление хобота, анимация шагов кипера во все 4 стороны, частицы сена и брызг.
  - HUD: стильный деревянно-латунный ретро-борд сверху (часы, чистота вольера, сытость слонов, индикатор тачки, кнопка звука) и компактный журнал событий в правом нижнем углу.

### 3. Key Product Decisions & Trade-Offs

- **Автономный чистый HTML5 Canvas в `index.html`**:
  - *Решение*: Вся разметка, CSS-стили, аудио-движок и движок рендеринга на Canvas собраны прямо в автономном `index.html`. Дополнительно файл совместим с локальным Vite-сервером.
  - *Почему*: Прямое требование пользователя («в ОДНОМ автономном файле index.html без внешних библиотек и тяжелых ассетов»), мгновенный запуск в любом браузере, нулевое время загрузки.
- **Процедурная генерация тайлов и спрайтов через Canvas API**:
  - *Решение*: Деревянные доски, солома, ворота, металлические решетки кормушек, слоны и персонаж кипера рисуются процедурно пиксельными примитивами и генератором текстур.
  - *Почему*: Абсолютная автономность, отсутствие риска битых внешних картинок, идеальная четкость пикселей (`image-rendering: pixelated`).
- **Web Audio API синтезатор**:
  - *Решение*: Генерация звуков через `AudioContext` (осцилляторы волн sine/sawtooth/triangle, генератор белого шума для лопаты/шагов, частотная модуляция для трубного слоновьего гласа).
  - *Почему*: Никаких внешних mp3/wav, мгновенная реакция без задержек.

- **Сущности и Состояние**:
  - `gameState`: `'TITLE'` | `'PLAYING'` | `'INSPECTING'` | `'QTE_URINE'` | `'PAUSED'` | `'SHIFT_END'`.
  - `time`: `hour` (8..20), `minute` (0..59), плавный отсчет времени со скоростью ~1 минута игры = 0.8с (~9.6 минут реального времени на 12-часовую смену).
  - `player`: `x, y, vx, vy, dir, walking, wheelbarrowKg (0..60), carryingItem (none / hay / mash / bucket), stats: { manureKg, foodFed, urineSamples, inspections }`.
  - `elephants`: массив из 3 слоних:
    - *Одри* (старшая, спокойная, любит сено),
    - *Марго* (активная, часто требует внимания и каши),
    - *Претти* (молодая, игривая, машет ушами).
    - Каждая слониха имеет `satiety` (0..100%), таймер нужды в туалете, таймер анализа мочи, текущую анимационную позу и здоровье.
  - `piles`: координаты куч навоза на полу слоновника.
  - `feeders`: кормушки для каждой слонихи с уровнем заполнения.
  - `fodderBales` & `fodderMash`: зоны склада с запасами еды.
  - `wasteContainer`: бак для утилизации навоза из тачки.
  - `logs`: массив последних событий зоопарка с таймкодом.

- **Коллизии и физика**:
  - AABB (Axis-Aligned Bounding Box) для стен, перегородок, ворот и слонов.
  - Плавное скольжение вдоль стен при диагональном движении.

- **Файловый план**:
  - `index.html`: автономный самодостаточный файл со всей игрой, разметкой, CSS-стилизацией, Canvas и JavaScript.
  - `metadata.json`: актуализация названия и описания («Симулятор дежурного кипера слоновника»).
  - `src/App.tsx`: подключение обертки или редиректа для согласованности с Vite-сборщиком.
