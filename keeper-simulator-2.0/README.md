# Симулятор дежурного кипера слоновника 2.0

Автономная 2D Canvas-игра о дневном дежурстве в павильоне трёх слоних: Одри, Марго и Прэтти. Основная игровая логика находится в `index.html`; сервер и ключи API не требуются.

## Запуск

Можно открыть `index.html` прямо в современном браузере. Для локального сервера с Vite:

```bash
npm install
npm run dev
```

## Управление

- **WASD / стрелки** — движение.
- **E** — взаимодействие: корм, уборка, поилка, стол дежурного и другие объекты.
- **F** — осмотр слонихи рядом с кипером.
- **Tab / T** — планшет дежурного с планом и чек-листом смены.
- **P / Esc** — пауза; Esc также закрывает планшет и карточку осмотра.
- **Space / Enter** — начать смену, подтвердить действие в мини-игре или начать новую смену по итогам.
- **M** — включить или выключить звук.

На сенсорном экране доступны экранный джойстик и кнопки действий. Соотношение игрового поля 1000 × 680 сохраняется при масштабировании.

## Основные механики 2.0

- Дневная смена с 08:00 до 20:00 и интерактивный планшет с задачами четырёх фаз.
- Уникальные модели поведения Одри, Марго и Прэтти.
- Связанные показатели сытости, жажды, кормушек и состояния поилки.
- Чистое лабораторное ведро требуется для отбора пробы мочи.
- Частичная загрузка навоза с сохранением остатка в куче при заполнении тачки.
- Мир останавливается при открытии планшета, карточки осмотра и экранов паузы; мини-игра отбора пробы продолжает только собственную шкалу.
- Вечерний табель оценивает благополучие животных, чистоту и воду, медицинский уход и журнал, а также выполнение регламента.

Проект использует пиксельную графику, Canvas 2D и Web Audio API.
